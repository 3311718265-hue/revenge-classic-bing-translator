Bing Bilingual Translator

为 Discord 原文下方提供译文显示。支持自动翻译、当前频道批量翻译、停止、清除和目标语言切换。

0.1.2 修复生成消息行被复制后，原生消费者可能仍使用原对象的问题。已有用户请在插件菜单选择 Refetch 并重启 Discord，无需重复安装。实际手机译文显示仍待确认。

完整使用指南与故障处理 · Revenge Manager 官方下载

Source URL

  1. 打开 Revenge Classic 的设置 → Plugins，点击添加插件。
  2. 粘贴上面的 Source URL，安装并启用。
  3. 打开插件设置，确认目标语言和渲染诊断，再进入频道。

验证范围

Bing 网页接口和安卓适配仍为实验性。0.1.1 的手机反馈确认消息读取及译文获取，但没有显示中文；0.1.2 已执行本地构建和 69 项自动测试，实际手机修复效果未确认。Microsoft Translator 可作为手动配置的官方选项。

只翻译已加载消息，不主动下载 Discord 历史。原文不会被覆盖；聊天文本会提交至所选的 Microsoft 翻译服务。
