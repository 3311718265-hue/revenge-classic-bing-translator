Bing Bilingual Translator

0.1.7 支持勾选指定的多条普通文字消息，再点击“翻译所选”。译文分别显示在原文下方，不弹译文窗口。

进入插件设置 → 选择多条消息 → 逐条勾选 → 翻译所选。进入多选会暂停自动翻译；需要时可重新开启自动翻译新消息。已安装用户请选择 Refetch 并重新加载，确认版本为 0.1.7。

完整使用指南与故障处理 · Revenge Manager 官方下载

Source URL

  1. 打开 Revenge Classic 的设置 → Plugins，点击添加插件。
  2. 粘贴上面的 Source URL，安装并启用。
  3. 打开插件设置，确认目标语言和渲染诊断，再进入频道。

验证范围

Bing 网页接口及安卓适配仍为实验性。92 项本地检查通过，覆盖只翻译所选、顺序、缓存、停止、编辑刷新及无结果弹窗。多选功能发布后仍须在手机确认。

嵌入卡片（embed）、图片及附件暂不支持。只翻译已加载消息；正文发送至所选 Bing/Microsoft 服务，译文不作为新 Discord 消息发送。
