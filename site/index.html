Bing Bilingual Translator

安卓长按普通文字消息，选择“翻译这条消息”，无需选中句子。也可在插件设置开启自动翻译，在原文下方显示译文。

0.1.5 修复误将 Discord 语言代理识别为菜单组件的问题。本次修复代码已在一台安卓手机显示长按翻译按钮；普通正文双语显示已实机看到。已安装用户请选择 Refetch 并重启 Revenge，确认诊断版本为 0.1.5。

Source URL

  1. 打开 Revenge Classic 的设置 → Plugins，点击添加插件。
  2. 粘贴上面的 Source URL，安装并启用。
  3. 打开插件设置，确认目标语言和渲染诊断，再进入频道。
