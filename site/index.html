Bing Bilingual Translator

安卓长按普通文字消息，选择“翻译这条消息”，或在插件设置开启自动翻译。译文直接显示在对应原文下方。

0.1.6 取消翻译成功后的译文弹窗，手动、自动都只显示原文下方的译文。已有用户选择 Refetch 并重新加载，确认插件诊断版本为 0.1.6。

完整使用指南与故障处理 · Revenge Manager 官方下载

Source URL

  1. 打开 Revenge Classic 的设置 → Plugins，点击添加插件。
  2. 粘贴上面的 Source URL，安装并启用。
  3. 打开插件设置，确认目标语言和渲染诊断，再进入频道。

验证范围

Bing 网页接口及安卓适配仍为实验性。0.1.5 在 Android 16 / app.revenge 348.10 / Classic 1b1d297-main 手机上已看到普通正文中文及手动译文弹窗。0.1.6 移除该额外弹窗，84 项本地检查通过；发布后手机实际效果仍须核对。

嵌入卡片（embed）、图片和附件暂不支持翻译，卡片长按直接复制的入口仍待适配。只翻译已加载消息，原文保留；正文会发送至所选 Bing/Microsoft 翻译服务。
