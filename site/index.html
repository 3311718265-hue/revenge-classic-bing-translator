Revenge Classic · JavaScript 插件

Bing Bilingual Translator

在 Discord 原文下方显示译文。自动翻译新消息和加载的历史消息，支持一键翻译当前频道、停止、清除和切换目标语言。

Source URL

  1. 打开 Revenge Classic 的设置 → Plugins，点击添加插件。
  2. 粘贴上面的 Source URL，安装并启用。
  3. 打开插件设置，确认目标语言和渲染诊断，再进入频道。

验证范围

Bing 网页接口为实验性接口。本地构建、自动测试和公开样例的实际翻译请求已执行；Android 16 / Discord 348.10 的手机运行尚未验证。Microsoft Translator 可作为手动配置的官方选项。

只翻译已加载消息，不主动下载 Discord 历史。原文不会被覆盖；聊天文本会提交至所选的 Microsoft 翻译服务。
